# 项目变更记录

以下记录以当前仓库历史和工作区代码为依据，按功能汇总至 2026-11-15。每次后续功能更新都在末尾追加一项，并在对应提交说明中记录验证结果。

1. 建立工程基线：采用 Electron、React、Konva、TypeScript 和 Vite；以 Zod 定义项目文档，编辑器统一管理画布状态，并通过受限 preload API 将文件操作交给 Electron Utility Process。
2. 实现项目生命周期：创建、列出、打开、保存项目；项目内划分 `assets/`、`cache/`、`recovery/`，保存时写入恢复快照，并在主文件损坏时尝试恢复。
3. 扩展画布编辑：加入文字、基本图形、图片、媒体轨道、箭头、画笔、分组、多选、撤销重做、相机平移缩放及文字属性；对应命令集中在 `src/core/editor.ts`。
4. 完善媒体策划：导入图片、音频、视频与文本；使用 FFmpeg/ffprobe 生成时长、音频波形和视频帧；支持播放、时间标记、裁剪、注释、媒体任务状态与缓存复用。
5. 增强持久化和测试：加入有界延迟自动保存、关闭窗口前冲刷、后台异常重启处理、媒体路径约束、单元测试、固定素材和 Electron 端到端用例；构建脚本负责准备媒体工具与 Windows 安装包。
6. 修复新建项目与浏览器导入：将 Electron 中不可靠的原生 `prompt` 改为界面内表单；为浏览器模式新增 IndexedDB 项目与素材存储、文件选择和 Blob 预览，并增加浏览器重开项目回归测试。
7. 增加项目目录设置：在顶部设置面板选择桌面版默认项目根目录；Electron 将设置写入 `userData/settings.json`，项目列表和新项目使用所选目录，已打开项目不被搬移。
8. 增加双语界面和免安装预览：简体中文与英语从顶部设置切换并持久化；`dev:desktop` 同时启动 Vite 和未安装的 Electron，`dev` 继续提供浏览器快速预览。
9. 整理工程资料：在 `agent/` 集中维护结构与变更记录，根目录 `AGENTS.md` 说明用法；清理临时测试目录和可重建缓存，保留测试样本、媒体工具授权信息与构建脚本。
