# 项目变更记录

本记录按功能组织，后续进展补充在对应条目下；未完成项以“未完成”标注，避免按时间形成重复流水。

1. 工程基线、桌面运行与构建
   - 使用 Electron、React、Konva、TypeScript、Vite 与受限 preload IPC；编辑器文档为渲染端唯一事实，文件操作由 Utility Process 执行。
   - 桌面开发数据、用户数据、运行日志、媒体工具准备和 Windows 安装构建均有固定路径及脚本；开发入口自动生成 Hello 字形路径。
   - 已验证：构建、单元测试与此前的沙箱外桌面冒烟可运行。Electron 桌面复测必须在沙箱外执行。
   - 已验证：`npm.cmd run dev` 的 Windows 控制台中文日志以 UTF-8 正常输出，开发窗口完成创建与页面加载。
   - 发布策略：在人工明确宣布稳定发布前，开发预览和人工检查统一使用 `npm.cmd run dev`，不生成或保留安装包；当前 `release/` 安装产物已清除。取得发布确认后才运行 `npm.cmd run dist:win`，并进行安装包图标、离线资源和安装流程验收。

2. 项目生命周期与统一存储格式
   - 项目含 `project.json`、`assets/`、`cache/`、`recovery/`；支持新建、列表、打开、自动保存、恢复快照与损坏恢复。
   - 当前格式为 `schemaVersion: 3`。读取历史项目或恢复快照时先迁移、校验关系、备份原件，再原子写回；失败不覆盖原文件。备份统一命名为 `pre-migration-*`，不向用户目录暴露中间版本称谓。
   - 笔记正文改为单一 Tiptap JSON，图片节点引用项目素材；批注 mark 与元数据使用稳定 ID。历史分块正文只保留在迁移入口。
   - 已验证：迁移保留相机、对象、素材、标记、连接和笔记关系；历史主文件、无笔记项目和恢复快照均可升级；无效引用不覆盖原文件且首页可重试打开。

3. 笔记与批注
   - 单个按需加载的 Tiptap 编辑器处理整页正文、跨段选区、中文组合输入、粘贴和撤销。笔记可编辑或阅读，双击画布缩略图进入阅读，关闭标签不删除内容。
   - 同一批注 ID 可标记多个正文片段；删除引用后保留批注并标为失效。右侧卡片根据正文 mark 的实际行盒避让排列，以细虚线正交折线连接；编辑、滚动、缩放与版心变化后自动重算。
   - 素材库插图、外部图片粘贴和拖入均通过受限 IPC 导入项目素材后写入光标位置。图片节点保存素材 ID、宽度和对齐，维持原始比例；复制笔记时同步重写批注 ID 和 mark。
   - 已验证：桌面用例覆盖中文输入、跨段批注、关闭与重开、真实图片拖入、图片宽度/对齐和重启后的持久化。
   - 阅读模式将正文保持为只读，同时把浏览器选区映射回 Tiptap 文档位置，允许对实际选中文本划线与新增批注；该行为已由桌面用例回归。

4. 画布、素材与连接线
   - 支持文字、图形、图片、媒体轨道、画笔、标记、分组、多选、撤销重做、相机平移缩放和素材导入。拖动使用顶层虚影，松开一次提交，右键、Esc、失焦或无效落点取消。
   - 图片支持比例锁定、数值裁剪和画布内可视裁剪框；裁剪框可拖动并能用四角调整，和数值字段共用同一份归一化裁剪数据。右下角保留加粗折线缩放柄与扩大透明命中区。
   - 连接线在顶层图层，支持直线、正交、曲线、圆角、虚线、自定义间隔、端点、标签、透明度和多选批量编辑。
   - 编辑面板已支持旋转、六向对齐、横纵分布、组合、解组和置顶/置底；连接线支持复制与粘贴样式。
   - 媒体标记拖出的文字批注通过独立顶层连接层绘制为可命中的虚线箭头，可选中后编辑样式或删除；桌面用例已覆盖标记、拖出、文本完成与连接关系保存。

5. 图库与属性编辑
   - 图库按 General、Basic、Arrows、Flowchart 四类组织，支持搜索和折叠。固定的图形标识、分组、SVG 路径、工具预览和画布渲染共用同一份定义；完整性测试确保 43 个可保存图形逐一具有对应标签和几何，杜绝预览或画布退化为方块。
   - 首页画布封面也复用该几何定义，保留图形轮廓、填充、边线和旋转，不再把图形降级为矩形。
   - 属性区统一为“编辑”，涵盖样式、颜色、文本、排列、图片比例和裁剪；主题采用 oklch Token，默认 Indigo Mono，Pantone 年度色标注近似换算来源。

6. 首页、开屏与视觉主题
   - Hello 使用本地字体路径按原时序描绘与淡出；项目卡使用玻璃文件夹组件及斜向散出动画，入口宽度为约 240 CSS px。
   - 开屏遮罩保持视觉动画并允许首页立即响应；项目打开失败后在首页保留错误信息与“重试打开”入口。
   - 首页仅使用真实项目内容：画布预览复现最后保存的相机视口，媒体和笔记使用实际内容；空项目不生成虚构预览。预览按项目修订缓存，列表读取不切换活动项目。
   - 玻璃文件夹改用纯二维前片平移与内容卡片分阶段上滑散出；降低前玻璃片的模糊和遮罩，让实际项目素材在静止态也露出边角，并将内页预览在裁切区域中放大 24%。设置新增“强制播放动画”，开启后覆盖系统的减少动态效果偏好。
   - 开发入口在 Windows 下静默切换 UTF-8 控制台，并以 UTF-8 解码中继 Electron 子进程输出，确保 Vite、Electron 和脚本的中文诊断可读。
   - 玻璃文件夹降低前片模糊、白色遮罩和高光强度，静止态文件栈上移并加大层叠距离，使真实项目素材在玻璃内可辨且上缘露出；首页截图脚本会先导入固定真实图片，再核对静止与展开状态。
   - 已验证：默认与 150% 设备缩放下的 Hello、空文件夹静止和散出截图均完成核对；ICO 将在取得稳定发布确认后的安装包中人工核验窗口、任务栏、快捷方式的一致性。

7. 验证与质量

   - 已验证：`npm.cmd run build` 与 `npm.cmd run verify` 通过；52 项单元测试和 7 项桌面用例通过。默认与 150% 缩放截图已完成视觉核对。
   - 历史发布验证已检查：此前生成的解包程序和 NSIS 安装器均嵌入 32×32 关联图标；离线 `ffmpeg.exe`、`ffprobe.exe` 与许可证文件已打入应用资源目录。当前安装包已按开发策略清除。
   - 安装包验证保留为发布确认后的专项检查；当前开发阶段只保留构建、回归和 `dev` 预览所需生成物。
   - 视觉验收以 `agent/visual-verification.md` 规定的“基线截图、差异观察、单一假设、小范围修改、同条件复拍、跨状态回归”闭环执行；`AGENTS.md` 和项目守则均提供入口与最低验收标准。
   - 项目协作守则新增任务完成闭环：以工作区基线区分既有改动，先复现和记录事实，再以可证据支持的根因实施单一修复，并按风险完成回归验证后如实交付。
