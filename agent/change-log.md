2. 项目生命周期与统一存储格式

3. 笔记与批注
   - 单个按需加载的 Tiptap 编辑器处理整页正文、跨段选区、中文组合输入、粘贴和撤销。笔记可编辑或阅读，双击画布缩略图进入阅读，关闭标签不删除内容。
   - 同一批注 ID 可标记多个正文片段；删除引用后保留批注并标为失效。右侧卡片根据正文 mark 的实际行盒避让排列，以细虚线正交折线连接；编辑、滚动、缩放与版心变化后自动重算。
   - 素材库插图、外部图片粘贴和拖入均通过受限 IPC 导入项目素材后写入光标位置。图片节点保存素材 ID、宽度和对齐，维持原始比例；复制笔记时同步重写批注 ID 和 mark。
   - 已验证：桌面用例覆盖中文输入、跨段批注、关闭与重开、真实图片拖入、图片宽度/对齐和重启后的持久化。
   - 阅读模式将正文保持为只读，同时把浏览器选区映射回 Tiptap 文档位置，允许对实际选中文本划线与新增批注；该行为已由桌面用例回归。
   - 新增 `@tiptap/extension-text-style` 的 TextStyleKit：字体族与字号作为 textStyle mark 只作用于非空文字选区，无选区时控件显示为空；行距与版心继续作为整篇设置。选区工具由 `@tiptap/react/menus` 的 BubbleMenu 承载，编辑与阅读模式均可用，阅读模式把浏览器选区映射回 Tiptap 位置后执行统一单色划线与批注。
   - 删除常驻多色划线/批注/插入图片菜单：图片仅经拖入或粘贴导入，选中图片显示独立上下文尺寸与对齐工具。正文改为亮白纸张，右侧批注区改为米白，批注卡片不再随划线颜色变化；正文使用固定行网格，按字体度量计算基线偏移，标题、列表与代码块占用整数倍行距。现有通用 mark 校验直接容纳 textStyle，schemaVersion 保持 3。
   - 已验证：行网格基线已按字体度量对齐到第一条线；版心通过对称内边距收窄并居中实际划线正文列；纸张与批注区在浅色、深色主题下保持可读；无选区时字体与字号控件为空。

4. 画布、素材与连接线
   - 支持文字、图形、图片、媒体轨道、画笔、标记、分组、多选、撤销重做、相机平移缩放和素材导入。拖动使用顶层虚影，松开一次提交，右键、Esc、失焦或无效落点取消。
   - 图片支持比例锁定、数值裁剪和画布内可视裁剪框；裁剪框可拖动并能用四角调整，和数值字段共用同一份归一化裁剪数据。右下角保留加粗折线缩放柄与扩大透明命中区。
   - 连接线在顶层图层，支持直线、正交、曲线、圆角、虚线、自定义间隔、端点、标签、透明度和多选批量编辑。
   - 编辑面板已支持旋转、六向对齐、横纵分布、组合、解组和置顶/置底；连接线支持复制与粘贴样式。
   - 媒体标记拖出的文字批注通过独立顶层连接层绘制为可命中的虚线箭头，可选中后编辑样式或删除；桌面用例已覆盖标记、拖出、文本完成与连接关系保存。
   - 音频波形由固定 1600×60 PNG 改为单声道 PCM 峰值缓存：后台解码为 8kHz 16-bit 单声道，按最高 120 列/秒聚合正负峰值，写入带版本头的二进制峰值文件；渲染端按裁剪区间与 pixelsPerSecond 重采样到屏幕像素列，以单个 Konva Shape 绘制 1px 垂直峰值线，缩放、拉长、裁剪与改色不重新分析音频。
   - 图片新增「还原比例」：读取素材自然尺寸，存在裁剪时按可见区域比例，保持高度不变重算宽度并重新启用锁定；不新增图片比例字段，解码失败保留当前尺寸并提示。
   - 创建型手势补齐虚影与取消语义：媒体标记拖出文本批注时随指针显示 220×72 文本框虚影，悬停已有文本对象显示命中反馈，松开一次性提交；工具放置、素材放置、移动/缩放、裁剪/时间缩放、连线与画笔均保留虚影或路径预览，右键、Esc、失焦与无效落点可取消。

5. 图库与属性编辑
   - 图库按 General、Basic、Arrows、Flowchart 四类组织，支持搜索和折叠。固定的图形标识、分组、SVG 路径、工具预览和画布渲染共用同一份定义；完整性测试确保 43 个可保存图形逐一具有对应标签和几何，杜绝预览或画布退化为方块。
   - 首页画布封面也复用该几何定义，保留图形轮廓、填充、边线和旋转，不再把图形降级为矩形。
   - 属性区统一为“编辑”，涵盖样式、颜色、文本、排列、图片比例和裁剪；主题采用 oklch Token，默认 Indigo Mono，Pantone 年度色标注近似换算来源。
   - 移除对象检查器独立“颜色”页签：统一颜色弹层嵌入填充、渐变、线条、文本、媒体轨道与连接线各自的颜色入口；弹层上部为可点击色板，下部为主题色 / Pantone / 自定义三个来源按钮，Pantone 扁平展示，自定义区支持取色、Hex 输入、收藏与删除收藏色，支持点击外部与 Esc 关闭。
   - ShapeIcon 统一为无填充、主题色描边、圆角连接的轮廓预览；箭头起点与终点头部由文字下拉改为带 SVG 线段与端点形状的可访问选项网格。

8. 工作台布局与模式切换
   - 新增受控组件 `WorkspaceModeSwitch`（接口 `mode: 'notes' | 'canvas'` 与 `onModeChange`），固定 160×36px、4px 内边距、76×28px 选区与 18px 笑脸小球，放在主顶栏撤销按钮左侧；两个原生按钮覆盖左右整块区域并使用 `aria-pressed`。灰色选区与小球分别平移，小球内层用 CSS 绘制双眼与笑脸，向右顺时针、向左逆时针各转满一圈，统一 240ms 缓动，快速反向从当前计算位置接续；设置 `-webkit-app-region: no-drag`，`prefers-reduced-motion` 下取消过渡。
   - `App` 显式持有工作台模式，不再用 `noteId !== null` 隐式判断；打开笔记或双击缩略图切到笔记，切回画布保留当前笔记与标签，重新进入时恢复，没有笔记时首次进入自动创建一篇；移除笔记内部“返回画布”按钮。新项目与每次打开项目默认进入画布模式，模式不写入项目数据。
   - `WorkspaceDock` 改为受控网格分栏：可见面板之间插入水平拖拽分隔线，拖动只调整相邻两块、总高度不变、每块最小 120px；侧栏宽度与三块面板高度写入用户 localStorage，窗口变化、面板隐藏或恢复时统一归一化与限幅，所有项目共享。分隔线支持键盘方向键每次调整 20px 并提供 ARIA separator 信息。
