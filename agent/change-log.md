# 项目变更记录

本记录按功能组织，后续进展补充在对应条目下；未完成项以“未完成”标注，避免按时间形成重复流水。

1. 工程基线、桌面运行与构建
   - 应用与锁文件版本统一为 0.2.0，下载说明及文件名指向 v0.2；Linux 构建镜像标签读取应用版本。当前功能已通过构建、冒烟、146 项单元测试、3 项工程脚本测试及 37 项定向桌面用例；发行安装包的验证结果记录于对应 GitHub Release。
   - 使用 Electron、React、Konva、TypeScript、Vite 与受限 preload IPC；编辑器文档为渲染端唯一事实，文件操作由 Utility Process 执行。
   - 桌面开发数据、用户数据、运行日志、媒体工具准备和 Windows/Linux 发布构建均有固定路径及脚本；开发入口自动生成 Hello 字形路径。
   - 已验证：构建、单元测试与此前的沙箱外桌面冒烟可运行。Electron 桌面复测必须在沙箱外执行。
   - 已验证：`npm.cmd run dev` 的 Windows 控制台中文日志以 UTF-8 正常输出，开发窗口完成创建与页面加载。
   - v0.1 发布构建提供 Windows 安装版/便携版与 Linux AppImage、DEB、RPM；平台媒体工具固定版本并核验 SHA-256，Docker 只构建，宿主机执行桌面验证。中英文 README 提供特色、安装和可复现命令；校验脚本为五种产物生成 SHA256SUMS.txt。文字编辑修复后重新构建五种安装包并更新校验文件；Windows 安装、图标、离线媒体与卸载验证通过，便携版通过冒烟；Linux 解包程序和 AppImage 在 Ubuntu 24.04/WSLg 冒烟复测通过，DEB/RPM 已核对元数据与依赖，其他发行版尚未逐一实测。

2. 项目生命周期与统一存储格式
   - 项目含 `project.json`、`assets/`、`cache/`、`recovery/`；支持新建、列表、打开、自动保存、恢复快照与损坏恢复。
   - 当前格式为 `schemaVersion: 5`，画布文字与笔记统一使用结构化正文，形状调整参数与横竖排方向纳入校验和持久化；格式升级让旧桌面进程在版本核对阶段停止写入，避免静默丢弃新字段。读取历史项目或恢复快照时先迁移、校验关系、备份原件，再原子写回；历史画布文字按字面保留，失败不覆盖原文件。备份统一命名为 `pre-migration-*`，不向用户目录暴露中间版本称谓。
   - 笔记正文改为单一 Tiptap JSON，图片节点引用项目素材；批注 mark 与元数据使用稳定 ID。历史分块正文只保留在迁移入口。
   - 已验证：迁移保留相机、对象、素材、标记、连接和笔记关系；历史主文件、无笔记项目和恢复快照均可升级；无效引用不覆盖原文件且首页可重试打开。
   - 自动保存保留载入修订号，并在订阅建立时检查当前文档，修复快速新建后首个操作漏存；桌面冒烟覆盖立即添加对象、重开与后台重启后的保存恢复。
   - 修复打开失败后残留后台项目、首页不响应保存请求导致无法关闭：打开前核对桌面格式，失败清理后台状态，关闭监听覆盖整个界面生命周期；当前输入先失焦提交再保存。保存失败可返回编辑或主动放弃未保存修改。五项桌面用例验证纯文本迁移与原件备份、打开失败、开发进程过期、当前输入保存及失败退出。

3. 笔记工作区、Markdown 与阅读批注
   - 单个按需加载的 Tiptap 编辑器处理整页正文、跨段选区、中文组合输入、粘贴和撤销。笔记可编辑或进入固定的 Markdown 渲染模式，双击画布缩略图进入渲染模式，关闭标签不删除内容。
   - 导航、正文与目录/批注辅助栏形成稳定分区；增加全文搜索、收藏、多标签、复制、删除确认、专注、分屏、阅读与缩放。导航宽度及收藏为本机偏好，正文仍使用现有项目模型。
   - 正文工具包含标题、格式、列表、待办、表格行列操作、引用、代码、图片和链接；排版弹层中字体/字号仅设置选区，无选区时留空并禁用。横线默认开启并按段落对齐，正文为亮白纸面、批注为米白侧栏，深色使用对应主题。版心根据扣除滚动条后的实际正文宽度限幅；窄窗口只滚动正文/预览区域，批注固定在窗口右侧，连线优先锚定相邻预览中的原文。
   - 图片选择、粘贴和拖入均通过受限 IPC；图片保存素材 ID、尺寸和对齐。批注在辅助栏列表呈现并可定位原文，删除引用后保留失效提示，删除批注同步清除 mark；复制笔记重写独立批注 ID。
   - 查找装饰独立于正文，支持跨格式和 Unicode 索引；全部替换合并为一个可撤销事务。Markdown 导出保留标题、待办状态、表格、链接和项目图片相对路径。输入、预览与导出沿用单一结构化正文；源 Markdown 不再被序列化器转义。系统另存为 IPC 支持桌面实际导出。
   - 为保持选区与菜单稳定，正文先按 Tiptap schema 规范化再同步，React 只订阅正文、选区和格式状态；待办节点显式设置语义属性，让编辑节点和预览共用列表布局。批注获得焦点后隐藏正文浮动菜单，图片工具条根据图片实际位置避让正文边界，修正滚动与对齐后的漂移。补齐整篇选区的浮动菜单、Markdown 阅读选区到原文的定位、右侧批注正交虚线与同时打开分屏和批注。Markdown 支持提示块、代码高亮、脚注、公式、任务、图片嵌入和双链；重复文字、实体和 emoji 均有位置映射测试。
   - 浏览器夹具已验证标题/大纲、待办勾选、表格增行增列、选区字体字号、链接、查找替换与撤销、批注新增/删除、导出内容、搜索/收藏与专注；真实 PNG 样本验证图片渲染、尺寸/对齐及工具条定位，导入元数据和媒体协议由夹具提供。真实桌面新增阅读模式四色划线、批注折线、无路径剪贴板图片写盘、Markdown 导出、连续数值调整与一次撤销、工具/笔记虚影拖入及项目重命名用例。
